# ระบบ AI วินิจฉัยโรคแตงโม (Watermelon Disease AI)

ระบบถามตอบและวิเคราะห์โรคแตงโมจากภาพ พร้อมคลังข้อมูลยาป้องกันกำจัดโรคพืช ปุ๋ย และวิธีดูแลแปลง ภาษาไทยทั้งหมด

ผู้ใช้ถ่ายภาพอาการที่พบในแปลง ระบบจะตอบกลับเป็นข้อความว่า **เป็นโรคอะไร วิเคราะห์จากหลักฐานอะไรในภาพ
มั่นใจกี่เปอร์เซ็นต์** แล้วต่อด้วย **วิธีดูแล ยาที่ใช้พร้อมอัตราต่อน้ำ 20 ลิตร ระยะเก็บเกี่ยวปลอดภัย และโปรแกรมปุ๋ย**

---

## สิ่งที่ระบบทำได้

| ความสามารถ | รายละเอียด |
|---|---|
| วิเคราะห์โรคจากภาพ | ส่งภาพใบ เถา ผล หรือทั้งแปลง แล้วได้ผลเป็นลำดับความเป็นไปได้พร้อมเปอร์เซ็นต์ความมั่นใจ และเหตุผลว่าดูจากอะไรในภาพ |
| แยกสิ่งที่ไม่ใช่โรคติดเชื้อ | แยกอาการขาดธาตุอาหาร พิษสารเคมี ผลไหม้แดด น้ำท่วมขัง และความเสียหายจากแมลงหรือไร ออกจากโรคเชื้อรา แบคทีเรีย และไวรัส เพราะกลุ่มหลังนี้พ่นยาไปก็ไม่หาย |
| แชทถามตอบพร้อมแนบภาพ | ถามเรื่องอาการ ยา อัตราการใช้ โปรแกรมปุ๋ย หรือการดูแลตามระยะ และแนบภาพในแชทได้โดยตรง ระบบจะวิเคราะห์ให้แล้วจำบริบทไว้ตอบคำถามต่อเนื่อง เช่น "ถ้าไม่มียาตัวนี้ใช้อะไรแทน" |
| คลังความรู้ | โรคและอาการผิดปกติ 48 รายการ · ยาและปุ๋ย 98 รายการ · คำถามที่พบบ่อย 29 ข้อ · แหล่งอ้างอิง 37 รายการ |
| ทำงานได้โดยไม่มี API key | มีโหมดออฟไลน์ที่วิเคราะห์ภาพด้วยการวิเคราะห์สีและลักษณะแผล และตอบคำถามด้วยการค้นคืนจากคลังความรู้ |
| ต่อโมเดลที่เทรนเองได้ | ถ้ามีโมเดล ONNX ของตัวเอง ระบบจะนำผลมาผสมกับผลจาก AI เพื่อเพิ่มความมั่นใจ |

### หลักการออกแบบที่สำคัญที่สุด

> **AI ทำหน้าที่ "ระบุโรคจากภาพ" ส่วน "อัตรายาและปุ๋ย" ดึงจากไฟล์ข้อมูลที่ตรวจทานแล้วเท่านั้น**

โมเดลภาษาไม่ได้แต่งตัวเลขอัตราการใช้สารขึ้นเอง เพราะอัตราที่ผิดพลาดหมายถึงพืชเสียหาย สารตกค้างเกินมาตรฐาน
หรืออันตรายต่อผู้ใช้ ระบบจึงให้โมเดลเลือกเพียง "รหัสโรค" จากรายการที่กำหนด แล้วนำรหัสนั้นไปดึงแผนการจัดการ
จาก `data/` ซึ่งเป็นไฟล์ JSON ที่แก้ไขและตรวจสอบได้

## ติดตั้งและใช้งาน

```bash
git clone https://github.com/easy-web-p/444.git
cd 444
./run.sh
```

เปิดเบราว์เซอร์ที่ <http://localhost:8000>

### ติดตั้งเอง

```bash

pip install -r requirements.txt
cp .env.example .env          # แล้วใส่ ANTHROPIC_API_KEY ในไฟล์ .env
python -m uvicorn app.main:app --reload --port 8000
```

### ตั้งค่า API key (เพื่อใช้ความสามารถเต็มรูปแบบ)

ขอ API key ได้ที่ <https://console.anthropic.com/settings/keys> แล้วใส่ในไฟล์ `.env`

```ini
ANTHROPIC_API_KEY=sk-ant-...
MELON_MODEL=claude-opus-5-5
MELON_EFFORT_DIAGNOSE=high
MELON_EFFORT_CHAT=medium
```

ถ้าไม่ใส่ ระบบจะรันในโหมดออฟไลน์และแจ้งเตือนบนหน้าเว็บอย่างชัดเจน

## การใช้งาน

### 1. วิเคราะห์จากภาพ

เลือกหรือถ่ายภาพ ใส่ข้อมูลประกอบ (อายุต้น ระยะการเจริญ สภาพอากาศ สารที่พ่นล่าสุด) แล้วกดวิเคราะห์

ผลที่ได้ประกอบด้วย

1. **สรุปผล** — สิ่งที่ AI เห็นในภาพและข้อสรุปเป็นภาษาไทย
2. **สาเหตุที่เป็นไปได้** — เรียงตามความมั่นใจ แต่ละรายการบอกหลักฐานที่สนับสนุนและข้อที่ยังขัดแย้ง
3. **สิ่งที่ต้องทำทันที** และ **สิ่งที่ต้องไปตรวจเพิ่มในแปลง** เพื่อยืนยัน
4. **แผนการจัดการ** — สารเคมีพร้อมอัตรา กลุ่ม FRAC/IRAC ระยะพ่นซ้ำ และระยะเก็บเกี่ยวปลอดภัย, ชีวภัณฑ์, การจัดการแปลง, คำแนะนำปุ๋ย, การป้องกันรอบหน้า
5. **โรคที่อาการคล้ายกันและจุดแยก** เพื่อให้ตรวจสอบซ้ำได้เอง
6. **ความปลอดภัย** — สารที่เป็นพิษต่อผึ้ง ระยะเก็บเกี่ยวปลอดภัยที่นานที่สุดในแผน และกฎการใช้สาร

> ค่าเปอร์เซ็นต์ที่แสดงคือ **ระดับความมั่นใจของการวิเคราะห์** ไม่ใช่ความรุนแรงของโรค
> ถ้าต่ำกว่า 35% ระบบจะเตือนว่ายังไม่ควรตัดสินใจซื้อสารเคมีจากผลนี้

### 2. ถ่ายภาพอย่างไรให้แม่น

- ถ่ายในแสงธรรมชาติ เลี่ยงแดดจัดจนเกิดเงาแข็ง ไม่ใช้แฟลช
- ถ่ายใกล้แผล 15-30 ซม. ให้โฟกัสคมที่แผล
- ถ่ายเพิ่มอีกภาพในระยะไกลให้เห็นทั้งต้นหรือทั้งแปลง เพราะ**รูปแบบการกระจายของอาการ**ช่วยแยกโรคจากพิษสารและการขาดธาตุอาหารได้มาก
- ถ่ายทั้งด้านบนใบและใต้ใบ เพราะอาการของราน้ำค้าง ไรแดง และแมลงหวี่ขาวอยู่ใต้ใบ
- วางเหรียญหรือนิ้วข้างแผลเพื่อเทียบขนาด

### 3. แชทถามตอบ

ถามด้วยภาษาพูดได้เลย เช่น "ใบมีปื้นเหลืองและขุยสีเทาใต้ใบ ใช้ยาอะไร" หรือ "โปรแกรมปุ๋ยช่วงผลขยาย"
ระบบจะค้นคืนข้อมูลที่เกี่ยวข้องจากคลังความรู้มาเป็นบริบทก่อนตอบ และแสดงรายการแหล่งที่ใช้อ้างอิงท้ายคำตอบ

**แนบภาพในแชทได้โดยตรง** กดปุ่มรูปภาพข้างช่องพิมพ์ แล้วพิมพ์ข้อมูลประกอบไปด้วยได้
ระบบจะวิเคราะห์ภาพ แสดงการ์ดสรุปในบทสนทนา แล้ว**จำบริบทผลวินิจฉัยนั้นไว้** เพื่อให้ถามต่อเนื่องได้ทันที เช่น

- "ถ้าไม่มีสารตัวนี้ ใช้อะไรแทนได้"
- "ต้องพ่นกี่ครั้ง ห่างกันกี่วัน"
- "พ่นร่วมกับปุ๋ยทางใบได้ไหม"
- "อีกกี่วันถึงเก็บเกี่ยวได้หลังพ่น"

แถบสีเขียวเหนือช่องพิมพ์จะบอกว่ากำลังคุยต่อเกี่ยวกับผลใด กดปุ่ม "ล้างบริบท" เมื่อต้องการเริ่มเรื่องใหม่
และจากหน้าผลวิเคราะห์หรือหน้ารายละเอียดโรค มีปุ่ม "ถามต่อในแชท" ที่พาไปแชทพร้อมบริบทให้เลย

## API

| Endpoint | วิธี | หน้าที่ |
|---|---|---|
| `/api/health` | GET | สถานะระบบ โหมดการทำงาน และจำนวนข้อมูลในคลัง |
| `/api/diagnose` | POST | วิเคราะห์ภาพ (multipart: `image`, `context`) |
| `/api/chat` | POST | ถามตอบแบบรอคำตอบทั้งก้อน (รับ `diagnosis_context` เพื่อถามต่อเนื่องจากผลวินิจฉัย) |
| `/api/chat/stream` | POST | ถามตอบแบบสตรีม (Server-Sent Events) |
| `/api/diseases` | GET | รายการโรค กรองด้วย `group` และ `part` |
| `/api/diseases/{id}` | GET | รายละเอียดโรคพร้อมแผนการจัดการ |
| `/api/pesticides` | GET | รายการยา กรองด้วย `type`, `target`, `organic` |
| `/api/pesticides/{id}` | GET | รายละเอียดสารหนึ่งรายการ |
| `/api/fertilizers` | GET | โปรแกรมปุ๋ยและรายการปุ๋ย |
| `/api/crop` | GET | ข้อมูลการปลูกและดูแลแตงโม |
| `/api/faq` | GET | คำถามที่พบบ่อย |
| `/api/search?q=` | GET | ค้นหาข้ามคลังความรู้ทั้งหมด |

เอกสาร API แบบโต้ตอบดูได้ที่ `/docs` (Swagger UI)

ตัวอย่าง:

```bash
curl -X POST http://localhost:8000/api/diagnose \
  -F "image=@leaf.jpg" \
  -F "context=แตงโมอายุ 45 วัน ฝนตกติดกัน 3 วัน ใบล่างเป็นก่อน"

curl -X POST http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"โรคราน้ำค้างใช้ยาอะไร และสลับกลุ่มอย่างไร"}'

# ถามต่อเนื่องจากผลวินิจฉัย โดยส่งบริบทมาด้วย
curl -X POST http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"ถ้าไม่มีสารตัวนี้ใช้อะไรแทน",
       "diagnosis_context":"สาเหตุอันดับ 1: โรคราน้ำค้าง (รหัส downy_mildew) ความมั่นใจ 82%"}'
```

## แก้ไขและเพิ่มข้อมูลในคลังความรู้

ข้อมูลทั้งหมดอยู่ในไฟล์ JSON ที่ `data/` แก้ไขได้โดยตรงแล้วรีสตาร์ตเซิร์ฟเวอร์

เพิ่มโรคใหม่: เพิ่มรายการในไฟล์กลุ่มที่เหมาะสมใน `data/diseases/` โดยต้องมีฟิลด์
`id`, `name_th`, `pathogen_type`, `severity`, `affected_parts`, `symptoms`, `image_cues`,
`treatment`, `prevention` และทุกค่า `ref` ในส่วน `treatment` ต้องชี้ไปยังรหัสที่มีจริงใน
`pesticides.json` หรือ `fertilizers.json`

ตรวจความถูกต้องก่อนใช้งานจริงเสมอ:

```bash
python3 scripts/validate_data.py
```

สคริปต์จะตรวจรหัสซ้ำ ฟิลด์ที่ขาด การอ้างอิงข้ามไฟล์ที่ชี้ไปยังรายการที่ไม่มีอยู่
และเตือนเมื่อสารเคมีไม่ได้ระบุระยะเก็บเกี่ยวปลอดภัย

## เทรนโมเดลจำแนกภาพของตัวเอง (ไม่บังคับ)

```bash
pip install torch torchvision onnx onnxruntime

python3 scripts/fetch_data.py list          # ดูแหล่งชุดข้อมูลที่รองรับ
python3 scripts/fetch_data.py verify        # ตรวจว่าเครือข่ายเข้าถึงแหล่งใดได้บ้าง
python3 scripts/fetch_data.py fetch plantdoc

python3 scripts/train_model.py --list-classes
python3 scripts/train_model.py --check-data datasets/watermelon
python3 scripts/train_model.py --data datasets/watermelon --epochs 15
```

ชื่อโฟลเดอร์คลาสต้องตรงกับรหัสโรคในคลังความรู้ ระบบจึงจะเชื่อมผลทำนายเข้ากับข้อมูลยาและปุ๋ยได้
เมื่อเทรนเสร็จให้เพิ่มใน `.env`

```ini
MELON_ONNX_MODEL=models/watermelon_cls.onnx
MELON_ONNX_LABELS=models/watermelon_cls.labels.json
```

ระบบจะใช้ผลจากโมเดลนี้ผสมกับผลจาก Claude โดยเพิ่มความมั่นใจเมื่อทั้งสองแหล่งเห็นตรงกัน

## ข้อจำกัดที่ต้องรู้ก่อนใช้งาน

- **ไม่ใช่การวินิจฉัยที่ยืนยันแล้ว** เป็นเครื่องมือช่วยคัดกรองเบื้องต้นเท่านั้น
- **โรคไวรัสหลายชนิดแยกจากกันด้วยภาพไม่ได้** ต้องใช้ชุดตรวจ ELISA หรือ PCR ในห้องปฏิบัติการ
- **โรคทางรากวินิจฉัยจากภาพใบไม่ได้** เช่น ไส้เดือนฝอยรากปมและโรคเหี่ยว ต้องขุดรากหรือตัดเถาดู
- **อัตราการใช้สารเป็นแนวทาง** ความเข้มข้นของแต่ละยี่ห้อต่างกัน ต้องอ่านฉลากและใช้อัตราตามฉลากเสมอ
- **ต้องตรวจสอบสถานะการขึ้นทะเบียนสารกับกรมวิชาการเกษตร** เพราะรายการสารที่อนุญาตเปลี่ยนแปลงได้
- **ต้องเคารพระยะเก็บเกี่ยวปลอดภัย (PHI)** ทุกครั้ง เพื่อไม่ให้มีสารตกค้างเกินมาตรฐาน
- ข้อมูลเรียบเรียงสำหรับสภาพการปลูกในประเทศไทย อาจไม่ตรงกับพื้นที่อื่น

หากความมั่นใจต่ำหรือความเสียหายสูง ควรปรึกษานักวิชาการเกษตรในพื้นที่
หรือส่งตัวอย่างตรวจที่คลินิกพืชของกรมวิชาการเกษตรหรือมหาวิทยาลัยใกล้เคียง
